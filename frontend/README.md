# Auto Writer 前端

Auto Writer 的前端部分，基于 React + TypeScript + Vite + Shadcn/UI 构建。

## 开发环境设置

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

默认端口：`3413`（或 `5173`，取决于配置）

### 3. 构建

```bash
npm run build
```

## 桌面应用 (Electron)

详细说明请参考根目录的 `README.md`。

```bash
npm run electron
```
