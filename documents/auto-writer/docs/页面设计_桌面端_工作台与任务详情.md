# 桌面端页面设计说明（Desktop-first）

## 全局设计

### Layout
- 框架：应用级“顶栏 + 左侧导航（可选）+ 主内容区”混合布局。
- 主内容区：CSS Grid（12 栅格）用于工作台卡片与列表混排；任务详情用左右分栏（配置/可视化在左，日志/产物在右），窄屏时改为上下堆叠。
- 间距：8px 基准（8/16/24/32）；卡片内边距 16。

### Meta Information
- Title 模板：`{页面名} | 多智能体自动写作器`
- Description：`本地一键运行，多智能体异步生成与导出文档。`
- Open Graph（桌面应用可选）：title/description/type=website

### Global Styles（Design Tokens）
- 背景：#0B1220（深色）与 #F7F8FA（浅色，可切换；MVP 可先固定深色）
- 主色：#3B82F6（按钮/高亮）
- 成功/警告/错误：#22C55E / #F59E0B / #EF4444
- 字体：系统字体栈；字号：12/14/16/20/24
- 按钮：Primary/Secondary/Ghost；hover 提亮 6%，disabled 透明度 50%
- 链接：同主色，下划线仅 hover 出现

## 页面 1：工作台（任务列表）

### Page Structure
- 顶部：应用顶栏（左：产品名与运行态；右：全局设置入口）
- 内容：上方工具区（新建、搜索、筛选），下方列表区（表格/卡片切换）

### Sections & Components
1. 顶栏（Top App Bar）
   - 左侧：Logo/名称“Auto Writer”；右侧显示“Docker 运行态”徽标：`DB OK / API OK`（红黄绿三态）
   - 右侧：按钮“设置”（弹窗）、按钮“打开产物目录”（若可实现）
2. 工具区（Toolbar）
   - 主按钮：`+ 新建任务`
   - 搜索框：按标题/主题关键词
   - 筛选：状态（运行中/暂停/完成/失败/取消）
   - 排序：更新时间（默认倒序）
3. 任务列表（List/Table）
   - 列：任务名、状态、更新时间、最新版本、操作
   - 行操作：进入详情、导出最新产物
   - 空状态：引导创建第一个任务
4. 新建任务弹窗（Modal）
   - 字段：任务名、主题（必填）、资料（多行）、工作流模板（下拉）、产物格式（至少 Markdown）
   - 操作：取消、创建并进入详情
5. 全局设置弹窗（Modal）
   - LLM 配置：提供方、Base URL（可选）、默认模型、API Key（仅本地保存；展示为掩码）
   - 执行配置：最大并发、单步超时、重试次数
   - 保存提示：保存后对新 Run 生效

### Interaction States
- 状态徽标：running（蓝色旋转指示）、paused（黄色）、succeeded（绿色）、failed（红色）、canceled（灰色）
- 列表加载：骨架屏；错误：顶部 toast + 可重试

## 页面 2：任务详情（运行面板）

### Page Structure
- 顶部：面包屑 `工作台 / {任务名}` + 运行控制区
- 主体：左右分栏（Desktop-first）
  - 左栏（约 40%）：任务配置 + 工作流可视化
  - 右栏（约 60%）：事件/日志流 + 产物预览/版本

### Sections & Components
1. 顶部控制区（Header Controls）
   - 左：任务标题、状态、最近更新时间
   - 右：主要控制按钮
     - `启动`（draft）
     - `暂停`（running）
     - `继续`（paused）
     - `取消`（running/paused；二次确认）
2. 左栏：任务配置卡（Config Card）
   - 展示并允许编辑：主题、资料、工作流模板、目标字数/风格（若模板支持）
   - 规则：一旦启动运行则配置进入“锁定”只读（避免不可复现）；允许“复制为新任务”快捷按钮（可选）
3. 左栏：多智能体工作流面板（Workflow Panel）
   - DAG/步骤列表二选一（MVP 可先用步骤列表 + 当前高亮）
   - 每个节点展示：智能体名称、职责摘要、输入输出摘要
   - 点击节点：右侧日志过滤到对应 stepId/agentId
4. 右栏：事件与日志（Event Stream）
   - 实时流（SSE/WebSocket）：按时间追加
   - 过滤器：智能体/步骤、事件类型、关键字
   - 展示：STEP_STARTED/OUTPUT/SUCCEEDED/FAILED、错误堆栈（折叠）
5. 右栏：检查点与恢复提示（Checkpoint Hint）
   - 当 paused：提示“已保存检查点，可继续运行”
   - 当 canceled：提示“已取消，本次 Run 终止；可新建 Run 重新开始”
6. 右栏：产物预览与版本（Artifacts）
   - Tabs：`预览` / `版本` / `下载`
   - 预览：Markdown 渲染；若尚无产物显示占位
   - 版本：按 version + 时间戳列表；切换后更新预览
   - 下载：导出当前版本（至少 .md）

### Responsive Behavior
- >= 1024px：左右分栏；日志与预览同列上下分块
- < 1024px：变为单列堆叠（控制区 → 配置 → 工作流 → 日志 → 产物）

### Motion & Feedback
- 运行中：控制区显示进度条（基于当前 step/总 step 估算）
- 暂停/继续/取消：按钮置灰并显示短暂 loading；成功后 toast + 状态徽标更新
