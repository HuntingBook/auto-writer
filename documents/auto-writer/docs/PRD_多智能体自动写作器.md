## 1. Product Overview
面向桌面端的“多智能体自动写作器”，用于把你的主题/资料自动编排成可交付文档，并支持可控的异步运行（暂停/继续/取消）。
通过可视化工作台管理任务与产物，一键 Docker 启动后即可本地运行与协作。

## 2. Core Features

### 2.1 User Roles
| 角色 | 注册/进入方式 | 核心权限 |
|------|----------------|----------|
| 单机使用者 | 本地启动即用（无需登录） | 创建任务、配置模型密钥、运行/暂停/继续/取消、多智能体编排、导出产物 |

### 2.2 Feature Module
我们的桌面端需求由以下页面构成：
1. **工作台（任务列表）**：新建任务、任务列表/搜索、运行态总览、全局设置（模型与密钥）、快速导出。
2. **任务详情（运行面板）**：任务配置、智能体工作流可视化、异步控制（暂停/继续/取消）、日志与事件流、产物预览与版本。

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 工作台（任务列表） | 新建任务 | 创建写作任务：输入目标（题目/大纲/交付格式）、可选粘贴资料、选择工作流模板 |
| 工作台（任务列表） | 任务列表 | 浏览/搜索任务；展示状态（未开始/运行中/已暂停/已取消/已完成/失败）、更新时间、最近产物摘要 |
| 工作台（任务列表） | 全局设置 | 配置模型提供方与 API Key；设置默认模型、最大并发、超时、产物输出目录 |
| 工作台（任务列表） | 一键运行态入口 | 展示 Docker 运行态健康状态（后端/DB）；提供“打开任务详情”快捷入口 |
| 工作台（任务列表） | 导出 | 一键导出最新产物（Markdown/Docx/PDF 视项目实现而定，至少 Markdown） |
| 任务详情（运行面板） | 任务配置 | 编辑/锁定任务输入；选择智能体工作流（如：检索→提纲→写作→审校→排版）与参数（目标字数、风格、引用策略） |
| 任务详情（运行面板） | 多智能体工作流 | 显示智能体拓扑与当前节点；支持查看每个智能体的职责、输入输出与中间结果 |
| 任务详情（运行面板） | 异步控制 | 启动运行；运行中可“暂停/继续/取消”；展示当前步骤进度、预计剩余、重试次数 |
| 任务详情（运行面板） | 事件与日志 | 流式展示运行事件（步骤开始/结束、工具调用、错误）；支持按智能体/步骤过滤与复制 |
| 任务详情（运行面板） | 产物与版本 | 预览产物；查看版本列表与差异（至少按版本时间戳切换）；支持导出指定版本 |

## 3. Core Process
**桌面使用者流程**
1. 在工作台点击“新建任务”，填写主题/资料，选择工作流模板与产物格式。
2. 点击“启动运行”，进入任务详情查看多智能体执行；可随时暂停（保留检查点）、继续或取消。
3. 运行完成后在任务详情预览产物，必要时基于版本回溯或重新运行部分步骤（以“重跑步骤”作为可选扩展，不作为必须）。
4. 在工作台或任务详情一键导出最终产物。
