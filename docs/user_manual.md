# 用户手册 (User Manual)

欢迎使用 Auto Writer —— 你的全自动网文创作助手。

## 1. 快速开始

### 第一步：创建小说
1. 点击首页“新建小说”或右上角“+”。
2. 填写**小说名称**（可留空）。
3. 选择**类型、风格、目标读者**。
4. 设定**总字数**与**单章字数**。
5. **核心步骤**：详细填写**世界观与故事背景**。
   - 提示：背景设定越详细，AI 生成的逻辑越严密。
6. 点击“确认创建”。

### 第二步：配置模型
1. 进入小说详情页。
2. 点击右上角“DeepSeek”。
3. 输入你的 **DeepSeek API Key**（可选）。
4. 未配置 Key 时系统会自动使用演示模式（不请求外部模型），用于跑通流程与体验功能。
5. 保存配置（密钥不会写入数据库；也可通过环境变量提供）。

### 第三步：生成大纲
1. 在“创作工作流”面板，默认处于“大纲策划”页。
2. 点击“生成大纲”。
3. 右侧日志面板将显示生成进度。
4. 生成完成后，你可以手动微调大纲文本，然后点击“保存为新版本”。

### 第四步：确定书名
1. 切换到“书名生成”页。
2. 点击“生成书名”。
3. AI 将提供 12 个候选书名，点击你喜欢的一个即可选中。
4. 你也可以点击已选书名旁边的“铅笔”图标，手动修改书名。

### 第五步：章节编排
1. 切换到“章节编排”页。
2. 点击“生成编排”。
3. AI 将基于大纲规划全书结构。生成完成后，下方将显示分卷列表。

### 第六步：正文生成
1. 切换到“正文生成”页。
2. 你可以看到所有待生成的章节。
3. **单个生成**：点击某章右侧的“生成”按钮。
   - 系统将依次生成：章节大纲 -> 章节细纲 (Beat Sheet) -> 正文。
4. **批量生成**：点击右上角“批量自动生成”。系统将自动排队生成所有未完成的章节。

### 第七步：阅读与导出
1. 切换到“沉浸阅读”页。
2. 点击左侧目录，阅读已生成的正文。
3. 可以在此页面查看该章对应的“章节大纲”与“细纲”。

## 2. 高级功能

### 知识库 (Knowledge Base)
- 点击右上角“知识库”按钮。
- 你可以添加设定资料、人物小传或参考素材。
- **作用**：AI 在生成过程中会检索知识库，确保生成内容符合你补充的设定。

### 暂停与恢复
- 生成过程中，你可以随时点击顶部“暂停”按钮。
- 稍后点击“继续”即可恢复任务。
