# 测试指南 (Testing Guide)

## 1. 测试策略

本项目主要依赖**端到端 (E2E) 手动验证**，辅以接口测试。

## 2. 验证清单 (Checklist)

### 2.1 基础功能验证
- [ ] **创建小说**：能否成功创建，数据库是否写入。
- [ ] **配置 Key**：在设置中配置 DeepSeek Key，是否保存成功。
- [ ] **知识库**：上传一段文本，能否保存；生成时 Agent 是否引用。

### 2.2 工作流验证
1. **生成大纲**：点击生成，观察日志面板是否有 SSE 流输出。
2. **生成书名**：生成后是否展示候选，点击选择是否更新界面。
3. **生成编排**：能否正确解析 LLM 返回的 JSON，生成分卷与章节列表。
   - *异常测试*：如果 LLM 返回格式错误，重试机制是否触发（日志中出现 Warn）。
4. **逐章生成**：
   - 生成章节大纲 -> 生成细纲 -> 生成正文。
   - 检查“沉浸阅读”页是否能看到对应内容。
   - 检查细纲是否包含场景/节拍。
5. **批量生成**：点击批量生成，是否自动轮询 Pending 状态的章节。

### 2.3 控制验证
- [ ] **暂停**：在生成过程中点击暂停，Worker 是否停止处理（可能需等待当前步骤完成）。
- [ ] **继续**：点击继续，任务是否恢复。
- [ ] **取消**：点击取消，任务状态是否变更，且不再有新日志。

### 2.4 UI 适配验证
- [ ] **桌面端**：双栏布局是否正常。
- [ ] **移动端**：是否自动堆叠，菜单是否可用。

## 3. 常见问题排查

- **SSE 连接失败**：通常是 Nginx 超时配置问题。已在 `nginx.conf` 中设置 `proxy_read_timeout 3600s`。
- **数据库连接错误**：检查 Postgres 容器是否健康。
- **Celery 任务不执行**：检查 Redis 连接，或 Worker 容器日志。
- **LLM 解析错误**：Agent 会自动重试 3 次。如持续失败，需优化 Prompt 或检查模型输出质量。
