# PRD 要点（智作 · 多智能体网文生成原型）

## 目标
- 桌面使用体验优先（后续可打包），同时提供 `docker compose up` 一键运行态便于验收。
- 输入小说基础设定后，按固定步骤通过多智能体协作生成：大纲 → 书名 → 章节编排 → 逐章正文。
- 生成过程必须异步可控：暂停 / 继续 / 取消，并实时展示各智能体执行过程。

## 功能范围（本轮原型）
- 藏书阁首页：历史小说列表、进入工作流、新建入口。
- 新建小说：输入类型/标签/读者（多选）、总字数、每章最少字数、背景。
- 工作流页：
  - 大纲：生成、编辑、保存新版本，再生成。
  - 书名：基于最新大纲生成多个候选，选择一个作为当前书名。
  - 编排：基于设定与最新大纲生成分卷 + 章节列表，并同步到章节表。
  - 逐章正文：只能逐章触发生成（批量时需轮询逐章）。
- 实时日志：事件流（SSE）展示智能体过程与片段预览。

## 非功能要求
- 自适配分辨率：桌面优先，窄屏自动堆叠布局。
- 数据必须真实落库（PostgreSQL），提供迁移与种子数据。
- 错误处理：前端不白屏（Error Boundary），请求失败 Toast。

## 关键交互
- 工作流每一步都有独立按钮触发生成，且显示最新版本信息。
- 运行控制：对当前 Run 支持暂停/继续/取消；日志面板实时更新。
